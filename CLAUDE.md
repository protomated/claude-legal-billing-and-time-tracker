# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

**PAC-80** — Legal Billing and Time Tracker. A Claude Desktop extension for solo and small-firm attorneys. Attorneys log billable hours, generate invoices, manage trust account activity, and check revenue by chatting naturally. There is no backend or relay — the extension writes directly from the attorney's machine to their own Google Sheet using their own Google account (OAuth).

The extension is packaged as a `.mcpb` (Desktop Extension bundle) — a ZIP archive containing a Node.js MCP server and a `manifest.json`. Claude Desktop has a built-in Node.js runtime; no installation required on the attorney's machine.

Landing page: `protomated.com/templates/legal-billing-time-tracker/` (WordPress — managed outside this repo).

## Commands

All commands run from the repo root.

```bash
# Validate MCPB structure (manifest, server entry point)
npm run validate

# Install server runtime deps into plugin/node_modules/
npm run install:server

# Full build: validate → install deps → pack → SHA-256
npm run build

# Pack only (skips validate; runs install:server first)
npm run pack

# Cut a GitHub release (runs build first; requires RELEASE.md at repo root)
npm run release

# Remove build artifacts
npm run clean

# List plugin files (excludes node_modules)
npm run tree
```

## Extension format

Output is a `.mcpb` file (ZIP renamed). Manifest version: `0.3`. Server type: `node`. Built-in Node.js in Claude Desktop — no runtime install needed.

The `manifest.json` declares:
- `server.type: "node"` with `entry_point: "server/index.js"`
- `server.mcp_config.args: ["${__dirname}/server/index.js"]` — path resolved by Claude Desktop at install time
- `user_config.spreadsheet_url` — collected from the attorney at install time; injected as `SPREADSHEET_URL` env var

## Architecture: direct OAuth + Sheets API

No relay, no service account. The MCP server runs locally on the attorney's machine.

```
Attorney installs .mcpb → pastes sheet URL → connects Google (one-time OAuth)
         ↓
Claude calls MCP tools (log_time, mark_billed, etc.)
         ↓
MCP server (Node.js, local) → Google Sheets API → attorney's Google Sheet
```

**OAuth:** The `connect_google` MCP tool opens a browser tab, runs a local callback server on port 8085, and exchanges the auth code for tokens. Tokens are saved to `~/.legal-billing/tokens.json` and auto-refreshed by google-auth-library.

**Spreadsheet ID:** Extracted from `SPREADSHEET_URL` env var (set from `user_config.spreadsheet_url`) at server startup.

## MCP tools

| Tool | Action |
|---|---|
| `connect_google` | Run OAuth flow; save tokens |
| `log_time` | Append row to Time Tracker tab |
| `mark_billed` | Update Unbilled → Billed for a client |
| `mark_paid` | Update Billed → Paid (requires explicit confirmation before call) |
| `add_trust_entry` | Append deposit or withdrawal to Trust Account tab |
| `get_dashboard` | Read Dashboard tab and return summary rows |

## Sheet column layout

**Time Tracker** (A–K): Date | Client Name | Matter Name | Matter Type | Description of Work | Hours Worked | Hourly Rate ($) | Total Fee (formula) | Invoice Status | Date Invoiced | Date Paid

**Trust Account** (A–I): Date | Client Name | Matter Name | Description | Deposits (+) | Withdrawals (-) | Running Balance (formula) | Bank Statement Balance | Difference

**Dashboard** (A–B): Label | Value (read-only; auto-calculated formulas)

## Before publishing — fill in two TBD placeholders

1. **`[GOOGLE_CLIENT_ID]`** and **`[GOOGLE_CLIENT_SECRET]`** in `plugin/server/auth.js`:
   - Create an OAuth 2.0 client in Google Cloud Console (type: "Desktop app")
   - Register redirect URI: `http://localhost:8085/oauth/callback`
   - Submit for Google OAuth verification (Sheets scope is sensitive — required for external users)

2. **`[TEMPLATE_SHEET_URL]`** in `plugin/README.md` (Step 1):
   - Publish the Protomated Legal Billing Google Sheet template
   - Replace the `[[TEMPLATE_SHEET_URL]]` placeholder with the actual URL

## Compliance constraints — non-negotiable

Enforced in `plugin/server/index.js` tool descriptions. Do not weaken:

1. **Trust disclaimer**: Every trust account output must carry "⚠️ Not legal advice — review against your state bar's trust-accounting rules."
2. **Billing disclaimer**: Every invoice and payment output must carry "⚠️ Not legal advice — review before sending to client."
3. **No legal advice**: Decline any request outside billing and time tracking.
4. **markPaid confirmation gate**: State what will change, wait for explicit confirmation, then call `mark_paid`.
5. **No undo**: Direct attorney to correct the row in their Google Sheet.

## Notes

- `plugin/node_modules/` is generated by `npm run install:server` and is included in the `.mcpb` bundle. Do not commit it to git (it is gitignored).
- The Google OAuth flow (port 8085) requires that port to be free. If it's in use, the `connect_google` tool returns an error telling the attorney to try again.
- `npm run release` passes `--notes-file RELEASE.md` to `gh release create` — update `RELEASE.md` before running.
- The Google Sheet template URL is TBD (`[TEMPLATE_SHEET_URL]`) — managed outside this repo.
